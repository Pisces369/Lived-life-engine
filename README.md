# LIVED — Codex Handoff

This repository package is a build specification and starter architecture for **LIVED**.

## Product
**LIVED** is one adaptive life-experience companion with two major movements:

- **Wayfinder** — expand the world.
- **Wayshower** — deepen the world.

Core promise:
> More life from the life you have.

Core product objective:
> Cultivate a life rich in peaks and texture while increasing agency.

## Start here
Codex should read:
1. `AGENTS.md`
2. `CODEX_HANDOFF.md`
3. `docs/product/PRODUCT_SPEC.md`
4. `docs/architecture/SYSTEM_ARCHITECTURE.md`
5. `docs/exec-plans/active/MVP_PLAN.md`

Then implement and test rather than producing another design-only response.

## Important
This package intentionally separates:
- coaching posture from expertise
- Wayfinder from Wayshower while keeping one head agent
- observed data from inference/forecast
- game mechanics from manipulative engagement
- excitement from permanent identity
- research from what is revealed to the user
