# LIVED Product Spec v0.6

## Product thesis
Most digital products compete for attention. LIVED should use intelligence to return attention to life.

> More life from the life you have.

LIVED is a persistent adaptive companion that helps users discover what feels alive, enter real-world experiences, build skills and courage at the edge of flow, travel intelligently, protect attention, remember meaningful moments, and increasingly create richness without needing the system.

## Two movements
### Wayfinder — FIND / change the place
Travel and exploration intelligence.

### Wayshower — SEE / change the lens
Everyday-life richness and interest/hobby development.

### REST
A first-class outcome. The system can intentionally decline optimization.

## Helping postures
Coach / Teacher / Guide / Agent / Companion.

Posture is independent of expertise. Example: photography can be taught, coached, guided, researched, or simply shared as companionship.

## Core loops
### Experience loop
SEE → WANT → CHOOSE → TRY → NOTICE → INTEGRATE → EXPAND

### Excitement loop
DETECT → TEST → EXPERIENCE → FEEDBACK → UPDATE → FOLLOW/REST/COMPLETE

### Travel loop
UNDERSTAND → DISCOVER → PRICE → VERIFY → DESIGN → EXPERIENCE → RECOVER → REMEMBER

## Life DNA
Store evidence with confidence and provenance, not categorical assumptions.

Suggested layers:
- enduring preferences
- current-life context
- domain skill estimates
- courage/novelty estimates
- excitement threads
- current edges (max 3)
- constraints
- accessibility/safety needs
- disliked experiences
- values/meaning hypotheses
- social preferences
- recovery patterns
- travel DNA

## Identity Evidence
Store observed/confirmed experiences that may support identity reflection, but never auto-assign labels.

## Success metrics
Avoid pure screen-time metrics.

Primary:
- real-world experiences entered
- experienced aliveness
- user-reported memorable moments
- agency / self-initiation
- successful preference learning
- appropriate challenge calibration
- attention returned to world
- travel value / true trip cost when applicable
- reduced coach dependency over time

Guardrails:
- notification burden
- recommendation rejection
- overwhelm
- repeated over-challenge
- over-inference
- excessive app interaction

## Surprise
Research everything. Spoil almost nothing.
Reveal information needed for safety, access, cost, closure, timing, or avoidable friction.
Preserve discovery when withholding detail creates upside without material downside.
